# أدوات البناء (للصفحات ما عدا المنيو)

- `npm run build:css` يبني `css/tw/<الصفحة>.css` من Tailwind. شغّله بعد أي تعديل على كلاسات Tailwind في الصفحات. إعدادات الألوان لكل صفحة في `tools/pages.js`.
- `npm run build:icons` يبني `css/icons.css` وخطوط الأيقونات في `fonts/` بالأيقونات المستخدمة فقط (Phosphor). أي أيقونة جديدة تُكتب `<i class="ph-bold ph-اسم"></i>` ثم شغّل الأمر.
- الخطوط مستضافة في `fonts/` وتعريفها في `css/fonts.css`.
- المكتبات الخارجية (QR، السحب والإفلات) في `js/vendor/`.

ملفات الناتج تنرفع مع المشروع، فـ Vercel ما يحتاج خطوة بناء.
