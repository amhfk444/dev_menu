سياسة الاستخدام المقبول

آخر تحديث: أكتوبر 2026

توضح هذه السياسة ما لا يجوز فعله عند استخدام منصة DEV MENU، حمايةً لعملائك وللمنشآت الأخرى وللمنصة. وهي جزء من الشروط والأحكام.

المحتوى الممنوع

  • منتجات أو خدمات يمنع بيعها أو الإعلان عنها في المملكة العربية السعودية.
  • أسعار أو عروض أو مكافآت مضللة، أو معلومات غذائية غير صحيحة.
  • محتوى مسيء أو مخالف للآداب العامة، أو يمس الدين أو الدولة أو أي شخص.
  • صور أو علامات تجارية أو نصوص لا تملك حق استخدامها.
  • انتحال اسم منشأة أخرى أو هويتها.

التواصل مع العملاء

  • تُستخدم رسائل العملاء وبطاقة الولاء والبيجر للتواصل مع عملاء منشأتك بشأن منشأتك فقط.
  • لا يجوز إرسال رسائل مزعجة أو متكررة بشكل مبالغ فيه، أو رسائل لا علاقة لها بمنشأتك، أو روابط ضارة.
  • لا يجوز تسجيل عملاء في بطاقة الولاء أو قائمة الانتظار دون علمهم، أو استيراد أرقام لم يوافق أصحابها على التواصل.

الاستخدام العادل للمنصة

  • لا يجوز التحايل على الأختام أو المكافآت أو منح أختام وهمية.
  • لا يجوز محاولة الوصول إلى حسابات أو بيانات منشآت أخرى، أو اختبار ثغرات المنصة دون إذن مكتوب منا.
  • لا يجوز تحميل المنصة ما يفوق الاستخدام المعتاد بطرق آلية، أو نسخ محتواها، أو إعادة بيع الخدمة.
  • لا يجوز مشاركة روابط الكاشير أو الحساب مع أشخاص خارج منشأتك.

عند المخالفة

يحق لنا حذف المحتوى المخالف، أو إيقاف الخدمة المعنية، أو إيقاف الحساب، بحسب جسامة المخالفة، ودون استرداد للمدة المتبقية إذا كانت المخالفة جسيمة أو متكررة. ولإبلاغنا عن محتوى مخالف لدى أي منشأة، تواصل معنا.
